# 파이썬 프로그래밍 기초 실습 및 과제

한국방송통신대학교 컴퓨터과학과 「파이썬 프로그래밍 기초」 강의를 수강하며 Google Colab에서 작성한 1~15강 실습 노트북과 과제 파일 모음.

## 폴더 구성

```
├── practice/      # 강의별 실습 노트북 (1~15강)
└── assignment/    # 과제 노트북
```

## 과제

[파이썬_기초_과제.ipynb](assignment/파이썬_기초_과제.ipynb)

| 문제 | 내용 |
|---|---|
| 1 | 문자열 연결을 이용한 환영 메시지 출력 |
| 2 | 총 초(sec)를 시·분·초로 변환 |
| 3 | 점수에 따른 학점(A~F) 판정 |
| 4 | 윤년 판별 |
| 5 | 입력한 단의 구구단 출력 |

과제 노트북 하단에는 직접 작성한 풀이와 AI를 활용해 작성한 풀이를 함께 수록하여 비교함.
